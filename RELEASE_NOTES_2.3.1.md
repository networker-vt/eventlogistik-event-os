# Orbit 2.3.1 — release notes

Calm Home after v2.3 feedback, plus freemium Credits. GitHub Pages `base` stays `/eventlogistik-event-os/`. Impressum: Mirco Küßner (unchanged).

## Home (5-second scan)

1. Greeting + one-line value (Matching + Deals für Jobs, Services, Reise, B2B)
2. Warm chips: **Was suchst du heute?** · **Was bietest du heute an?** · **Lass uns zusammen überlegen!**
3. One Assist field
4. One primary CTA — prefs-aware: **Präferenzen setzen – dann swipen** or **Find dein heutiges Match**
5. **Top Deals** (3–4, ranked from prefs + Assist + behavior, with a why-line)
6. **Match-Vorschläge** (max 6, mixed types + Match %)
7. **News** (max 4 glanceable headlines — curated/demo)
8. Tiny Credits peek

Speak/TTS and Create+ are off the first Home screen. Social/Reise dumps stay in Mehr / Wallet. No feature-tour walls.

## Match prefs gate

New users are not stranded on English “Set prefs first”. DE-first CTA: **Präferenzen setzen – dann swipen**. After prefs, Match opens a deck. Default locale is DE unless the user saved another language.

## Credits freemium

See [CREDITS.md](./CREDITS.md). Pack purchase is a **stub** (no Stripe/PayPal). Daily 20 free swipes; extra pack is a boost. Travel deep-scan, listing boost, featured social, priority interview cost Credits.

## Demo honesty

Travel cards and checkout show **Demo** before book. Wallet banner is louder: **Demo — kein echtes Geld**. News is labelled curated/demo.
