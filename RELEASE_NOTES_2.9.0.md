# Orbit 2.9.0 — release notes

Marketplace-first setup and a visible Orbi on Home. GitHub Pages `base` stays `/eventlogistik-event-os/`. Impressum: Mirco Küßner (unchanged).

## What changed

1. **Setup** replaces the three job/company role cards. Orbi asks for a free-text sentence (optional voice with an explicit mic consent; text fallback when Web Speech is missing). Three light steps: today, language and radius, interests. Skip still works. Login stays deferred until save or pay. The sentence is parsed locally into prefs.
2. **Home Orbi** is a large hero, not a tiny head. First run: Orbi introduces itself and can start setup. Later taps open one short tour (dismiss with “Tour nicht mehr zeigen”) or one adaptive question from recent prefs/usage — not a stack of menus.
3. **Copy** leads with the everything-marketplace (Reise, Kabine, Lernen, Jobs, Services, B2B). Tagline is no longer “Matching statt Spam” / “für Arbeit”. Match stays in the nav; the deck line covers offers and requests across categories.

## Keep

Assist-first Home. Basis Orbi stays free. 21M cap and fail-closed ledger untouched. Kids: no credits, no dating, no social connects. Demo stubs stay labeled Demo. Pages base `/eventlogistik-event-os/`.
