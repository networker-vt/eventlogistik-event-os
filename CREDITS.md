# Orbit Credits (v2.3.1)

Freemium in-app currency. **Demo ledger** until Stripe/PayPal + KYC are live. Pack checkout is a stub: credits appear locally, nobody is charged.

## Always free

- Assist ask
- Browse Match + **20 swipes / day**
- Basic chat (Match / Booking / Support)
- Wallet view
- Social read

Core discovery is never paywalled. Extra swipes after the daily 20 are a **boost**, not a lock on opening Match.

## Welcome

+50 Credits on first open (once). Referral and prefs/profile bonuses stay as before — see Wallet → Faire Rewards.
