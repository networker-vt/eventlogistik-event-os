# Accessibility (Orbit v2.1)

Orbit is a mobile-first PWA. Choices in this release:

- **Skip link** to `#main-content` on every screen.
- **Focus**: `:focus-visible` rings use the section `data-theme` accent. Mouse clicks do not leave a persistent outline (`:focus:not(:focus-visible)`).
- **Tap targets**: nav, stars, Interesse, and file pickers are at least 44×44px (`tap-target` / `min-h-11`).
- **Motion**: existing animations already wrap in `prefers-reduced-motion: reduce`. Themes do not add extra motion.
- **Contrast**: dark surfaces with accent text; optional Ideen-Box contrast tweak (`html.tweak-contrast`) still available. Muted text is `#a3a3a3` on `#0a0a0a`.
- **Semantics**: one `h1` per page, section `h2`s, `nav aria-label="Primary"`, `main` landmark.
- **Language**: `document.documentElement.lang` follows the Mein Bereich switcher (DE/EN; ES/FR/PL stubs set `lang` but copy falls back to EN).
- **TTS**: Web Speech API “read aloud” on Home hero, Match job cards, listing detail, Photo, Interview, Erfahrungen. Users can stop. Unsupported browsers get a visually hidden note.
- **Keyboard**: Match deck — ArrowLeft skip, ArrowRight/Enter Interesse. Dialogs (Create sheet) close with Escape.
- **Forms**: labels on inputs; star ratings as `radiogroup`; file inputs have visible triggers.
- **Honest demos**: photo “vision”, video call, and credits are labelled as stubs so assistive tech is not implying live payments or WebRTC.

Limits: not a full WCAG audit. High-contrast OS themes and screen-reader walkthroughs still need a human pass before a store listing.
